# Synapse System Solutions website

The public site for Synapse System Solutions, live at https://synapse-system-solutions.github.io/

One static page (`index.html`) in English and Arabic: the **عربي / EN** button in the nav switches language and layout direction. Add `#ar` or `#en` to the URL to link straight to one language.

## Editing

- All text, styles and scripts are in `index.html`. Arabic copy lives in the `T` dictionary near the top of the main script.
- Before launch, fill in `CONTACT = {whatsapp:"", email:""}` in `index.html`. Until then the contact form only builds a message to copy.
- Push to `main` and GitHub Pages republishes in about a minute.
